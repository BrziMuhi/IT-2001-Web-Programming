# IT-2001-Web-Programming
Project for course IT-2001-Web-Porgramming

Verdant — Restaurant Wev Application 


Project description
Verdant is a restaurant website where visitors can browse the menu, learn about the restaurant, send contact messages, and request table reservations. The project also plans registered customer accounts and an administration interface for managing restaurant data.

Roles:
Admin:Manages restaurant tables and reservations.
Adds, updates, and deletes menu items and categories.
Manages registered users.
Views and manages customer contact messages.
User(Customer):
Registers and logs into their account.
Browses the restaurant menu and food categories.
Makes and manages table reservations.
Views restaurant information and contacts the restaurant.
